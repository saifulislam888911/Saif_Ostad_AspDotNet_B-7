" Create a C# class called Book that represents a book in a library. The class should have:
1. Properties:
   - Title (string): The title of the book
   - Author (string): The author of the book
   - Pages (int): The number of pages in the book
   - IsAvailable (bool): Whether the book is available for borrowing
2. Constructor:
   - A constructor that initializes Title, Author, and Pages, and sets IsAvailable to true
3. Methods:
   - BorrowBook(): Sets IsAvailable to false and prints "Book has been borrowed"
   - ReturnBook(): Sets IsAvailable to true and prints "Book has been returned"
   - DisplayInfo(): Prints the book's title, author, number of pages, and availability status
Task: Write the Book class with the specified properties, constructor, and methods.
Example Usage:
Book book = new Book("Deyal", "Humayun Ahmed", 195);
book.DisplayInfo();
book.BorrowBook();
book.DisplayInfo();
book.ReturnBook();
book.DisplayInfo();
Expected Output:
Title: Deyal, Author: Humayun Ahmed, Pages: 195, Available: True
Book has been borrowed
Title: Deyal, Author: Humayun Ahmed, Pages: 195, Available: False
Book has been returned
Title: Deyal, Author: Humayun Ahmed, Pages: 195, Available: True
Comments in your code explaining how each example shows the pillar. "
