# Assignment-3 :
Requirements / Questions : 

" Create an ASP.NET web application using ADO.NET 
to perform CRUD (Create, Read, Update, Delete) operations 
on a SQL Server database table called Students 
using stored procedures. 
The application should have a simple web interface to interact with the database.

Requirements :
 1. Create a SQL Server database with a table named Students having the following columns:

    StudentId (int, primary key, identity)
    FirstName (varchar(50))
    LastName (varchar(50))
    Age (int)

 2. Create four stored procedures in SQL Server:

    sp_InsertStudent: Inserts a new student record.
    sp_GetAllStudents: Retrieves all student records.
    sp_UpdateStudent: Updates an existing student record by StudentId.
    sp_DeleteStudent: Deletes a student record by StudentId.

 3. Create an ASP.NET web application (using ASP.NET Web Forms or MVC) with ADO.NET to:

    Connect to the SQL Server database.
    Perform CRUD operations by calling the respective stored procedures.

Provide a web interface to:
 -Display all students in a table.
 -Add a new student via a form.
 -Edit an existing student’s details.
 -Delete a student. "
